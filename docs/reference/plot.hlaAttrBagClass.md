# Plot a "hlaAttrBagClass" object

To show a scatterplot of the numbers of individual classifiers and SNP
positions.

## Usage

``` r
# S3 method for class 'hlaAttrBagClass'
plot(x, ...)
```

## Arguments

- x:

  an object of
  [`hlaAlleleClass`](https://normanlabucd.github.io/PONG2/reference/hlaAlleleClass.md)

- ...:

  further arguments passed to or from other methods
