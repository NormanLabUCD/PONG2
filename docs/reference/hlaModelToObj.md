# Convert “hlaAttrBagClass” to “hlaAttrBagObj”

Convert
[`hlaAttrBagClass`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagClass.md)
to
[`hlaAttrBagObj`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagObj.md),
and
[`hlaAttrBagObj`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagObj.md)
can be written to the specified file with an external representation of
R objects.

## Usage

``` r
hlaModelToObj(model)
```

## Arguments

- model:

  an object of
  [`hlaAttrBagClass`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagClass.md)

## Value

Return an object of
[`hlaAttrBagObj`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagObj.md).
