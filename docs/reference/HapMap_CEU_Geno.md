# SNP genotypes of a study simulated from HapMap CEU genotypic data

An object of
[`hlaSNPGenoClass`](https://normanlabucd.github.io/PONG2/reference/hlaSNPGenoClass.md)
of 60 samples and 1564 SNPs.

## Usage

``` r
HapMap_CEU_Geno
```
