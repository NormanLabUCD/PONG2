# Dispose a model object

Release all resources stored in the
[`hlaAttrBagClass`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagClass.md)
object. The HIBAG package allows up to 256
[`hlaAttrBagClass`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagClass.md)
objects stored in memory.

## Usage

``` r
hlaClose(model)
```

## Arguments

- model:

  an object of
  [`hlaAttrBagClass`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagClass.md)

## Value

None.
