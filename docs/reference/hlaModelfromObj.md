# Build a model from “hlaAttrBagObj”

Build a model from an object of
[`hlaAttrBagObj`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagObj.md),
which is stored in an R object file.

## Usage

``` r
hlaModelFromObj(obj)
```

## Arguments

- obj:

  an object of
  [`hlaAttrBagObj`](https://normanlabucd.github.io/PONG2/reference/hlaAttrBagObj.md)

## Value

None.
